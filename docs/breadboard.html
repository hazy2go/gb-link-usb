GB Link Breadboard

Pico 2 W, BSS138 level shifter and the cut DMG-04, using the pin map we measured. Hover a wire in the list to highlight it. Hole names are column letter + row number, e.g. j3.

  1. Pico

    USB end at the top. Left pins in column c, right pins in column h, rows 3 to 22. That leaves columns a, b and i, j free for jumpers.

  2. Level shifter

    Rows 26 to 31, straddling the gap: LV pins in column d, HV pins in column g. Pin order differs between modules: follow the printed labels, keep LV on the left and HV on the right.

  3. Power

    VBUS (pin 40) to HVj3 → j28
    3V3 OUT (pin 36) to LVi7 → c28
    GND (pin 38) to HV GNDj5 → j29
    GND (pin 3) to LV GNDa5 → a29

  4. Signals

    GP0 (pin 1) to LV1a3 → a26
    GP1 (pin 2) to LV2b4 → b27
    GP2 (pin 4) to LV3b6 → b30

  5. Link cable

    green, clock (SCK)→ i26 (HV1)
    red, data from GB→ i27 (HV2)
    blue, GND→ i29 (GND row)
    orange, data to GB→ i30 (HV3)

    Shield: twisted and taped, not connected.

  6. Before USB goes in

    Nothing from the Game Boy side may touch row 7 or row 28 left (3.3 V). Power rails are not used. Send a photo first, then plug in.
